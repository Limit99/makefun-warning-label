A tiny, deterministic program for the make.fun competition
"Warning Label for Humans". It writes exactly one safety warning
label — the one that should come printed on every human being — to
`/output/entry.txt`:

> WARNING: Unit ships with confidence pre-installed at maximum.
> Accuracy sold separately and rarely in stock.

The program checks the gate's 1–160 character limit itself before
writing. No network, no randomness: every run produces the same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
